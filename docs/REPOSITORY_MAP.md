# Repository and evidence map

## Reviewer path

```text
reviewer/__main__.py
    ├── validation/check_bel_tables.py
    ├── validation/audit_selection_rankings.py
    └── validation/plot_submission_figures.py
                 │
                 ├── reads paper_results/v1/
                 └── writes outputs/reviewer/
```

The published snapshot has 60 matched-harness runs, 9 MLII sensitivity runs
and 60 subject-grouped runs. `manifest.json` and `SHA256SUMS` identify exact
snapshot bytes. `table_values.json` supplies the unrounded table reference values.

## Evidence map

All result paths in this table are relative to `paper_results/v1/results/`.
The local-only manuscript comparison and public snapshot check share the same
table calculation functions.

| Evidence | Public source | Calculation or interpretation |
|---|---|---|
| Table 1 baseline and three ResMemECG runs | `tables/per_class_ds2.json`, `tables/matched_diagnostics.json` | Five-class confusion counts preserve Q errors |
| Table 2 own results | `matched_recipe/full_seed{42,123,456}.json` | Published external-method rows are checked against their cited sources separately |
| Table 3 matched controls | `matched_recipe/*.json` | Three-seed macro F1 mean/SD and per-class metrics |
| Table 4 implementation ablations | `matched_recipe/*.json`, `tables/matched_diagnostics.json` | Paired-seed differences and conditional record-bootstrap summaries |
| Table 5 record-bootstrap contrasts | `tables/matched_diagnostics.json` | Stored paired intervals, positive-resample fractions and leave-one-record-out ranges |
| Table 6 transfer AUC | `tables/mechanism_transfer.json`, `tables/mechanism_lbbb*.json` | F-vs-rest logit margin evaluated on true F/N or F/L subsets |
| Table 7 per-fold full-model results | `controlled_mit_subject_cv/*.json` | Two-seed fold means and five-class confusion matrices |
| Table 8 six-core SG-CV comparison | `tables/sgcv_arch_runs.csv`, `controlled_mit_subject_cv/`, `sgcv_arch/` | Fixed-fold differences and descriptive uncertainty |
| MLII sensitivity table | `matched_recipe_mlii/*.json`, `tables/input_sensitivity.json` | MLII-by-name results and conditional paired contrasts |
| Supplement validation/test score tables | `tables/sgcv_arch_runs.csv` | Six core scores in each fold–seed cell |
| Exact record assignments | `tables/sgcv_record_partition.csv` | Records mapped to train/inner-validation/outer-test in all five folds |
| Per-split support | `tables/sgcv_fold_manifest.csv` | N/S/V/F/Q counts before and after training N control |
| Figure 3 seed confusion matrices | `tables/matched_diagnostics.json` | All three seed matrices and their sum |
| Figure 4 transfer diagnostic | `tables/mechanism_transfer.json` | Every stored seed/checkpoint of eleven configurations |
| Figure 5 validation/test agreement | `tables/ds2_validation_blindness.json`, `tables/sgcv_arch_runs.csv` | Configuration means and fold–seed-centred scores |
| Selection regret and seed-paired contrasts | `tables/ranking_cells.csv`, `tables/ranking_diagnostics.json` | Recomputed by the reviewer ranking step |
| Selective-prediction diagnostics | `p2_final/*.csv` | Stored empirical risk, coverage and referral counts |

`reviewer_report.json` records which steps ran and the code/environment used.
The CPU checker reproduces 729 table entries from the published aggregate inputs.
The map distinguishes stored bootstrap summaries from calculations regenerated by
the ranking and table modules.

## Model and training implementation

| File or directory | Role |
|---|---|
| `hmr_bilstm.py` | ResMemECG model, `RLSTMClassifier`, recurrent cells, CNN, attention and loss |
| `train_inter_patient.py` | Official recipe, training loop and shared configuration |
| `train_matched_recipe.py` | Matched architecture builders, cell/recipe ablations and paired-seed training |
| `validation/run_controlled_mit_subject_cv.py` | Locked five-fold subject-grouped protocol and full-model trainer |
| `validation/run_sgcv_arch.py` | Recurrent controls on the same controlled folds |
| `validation/preprocess_aami.py` | Original channel-0 DS1/DS2 input construction |
| `validation/preprocess_aami_mlii.py` | MLII-by-name sensitivity preparation |
| `validation/preprocess_lopo.py` | Mixed-source pool consumed by the controlled trainer |
| `validation/export_sgcv_fold_manifest.py` | Fold/record manifest generation from the controlled protocol |
| `validation/export_public_results.py` | Reviewed aggregate snapshot export with provenance and checksums |
| `configs/` | Experiment configuration and result-path helpers |

Training code and model modules retain their import paths so the documented
trainer commands and saved architecture keys remain usable.
