\noindent\textbf{ResMemECG: A Residual-Memory Recurrent Model for Inter-Patient
ECG Arrhythmia Classification with Subject-Grouped Rare-Class Evaluation}

\medskip
\begin{itemize}[leftmargin=1.4em,itemsep=4pt]
  \item A residual-memory recurrent cell blends a standard and a residual LSTM memory path.
  \item It leads all baselines on the MIT-BIH DS1/DS2 inter-patient benchmark.
  \item Controlled subject-grouped cross-validation exposes near-zero fusion-beat F1.
  \item Better supraventricular ranking gives no risk-controlled selective operating point.
  \item Fusion beats are recommended for expert referral in every tested setting.
\end{itemize}
